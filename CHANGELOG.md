## [1.0.0] - 2025-05-12

### Added
- Initial release
- CGEventTap-based discrete scroll interception
- CVDisplayLink animation engine with exponential decay smoothing
- Menu bar icon with Speed and Smoothness submenus
- Launch at Login support via SMAppService (macOS 13+)
- Hide Menu Bar Icon with settings panel fallback
- Auto-move to /Applications prompt on first launch
- Accessibility permission polling with automatic engine start
- UserDefaults persistence for speed, smoothness, and enabled state
